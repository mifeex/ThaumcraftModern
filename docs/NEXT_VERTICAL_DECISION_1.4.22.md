# Решение по следующей вертикали после 1.4.22

Статус: `BLOCKED_BY_SCOPE_CONFLICT`.

Этот документ фиксирует причину, по которой после стабилизационного барьера
нельзя честно начать вертикаль «жезл → узел в банке → вис → Arcane
Workbench» без решения владельца проекта.

## Главный блокер

В оригинальном Thaumcraft 4.2.3.5:

- деревянный стержень вмещает `25` vis каждого примального аспекта;
- железные наконечники имеют crafting cost modifier `1.1`;
- заключение узла в банку требует базовые `70` vis каждого из шести
  примальных аспектов;
- фактическое списание базовым iron-capped wand равно `77` vis каждого
  аспекта.

Следовательно, разрешённый master prompt базовый жезл физически не может
оплатить `NODEJAR`: `77 > 25`. Даже без модификатора наконечника `70 > 25`.

Классический следующий стержень Greatwood вмещает только `50`. Первый
обычный wand core достаточной ёмкости — Silverwood с capacity `100`, но его
получение требует запрещённой этой вертикалью Infusion и расширяет прогрессию
далеко за установленные границы.

`MASTER_PROMPT_1.4.19.md` прямо требует остановиться и объяснить блокер, если
нужна зависимость из запрещённого списка. Поэтому стоимость не снижена,
capacity базового жезла не увеличена и заглушечный survival-путь не добавлен.

## Связанные коллизии оригинальной прогрессии

1. Настоящая цепочка исследований:
   `NODES → NODETAPPER1 → NODEPRESERVE → NODEJAR`.
   `NODETAPPER1` — не пустой parent: он увеличивает перенос из узла с одного
   до двух vis за пяти-tick цикл.
2. Эффект `NODEPRESERVE` в TC4 специально не работает с деревянным стержнем
   или железными наконечниками. Единственное разрешённое снаряжение не может
   продемонстрировать механику этого исследования.
3. При capture классический код с вероятностью 75% ухудшает modifier:
   отсутствие modifier превращается в `PALE`. Это конфликтует с ограничением
   вертикали «только обычный modifier».
4. Очки откровения — arcane recipe с ненулевой стоимостью. Их нельзя
   изготовить до Arcane Workbench и заряженного жезла, хотя audit ставит их
   раньше зарядки и верстака.
5. Arcane Workbench создаётся не из vanilla crafting table, а из отдельного
   Thaumcraft Table. Для faithful loop нужен также сам Table и его классический
   рецепт.
6. Исследование `ARCANESTONE` содержит страницы `ArcaneStone1`–`ArcaneStone4`.
   Активация только первой страницы нарушает требование не оставлять
   unavailable pages.

## Варианты решения

### A. Fidelity-first, разбить вертикаль

Рекомендуемый вариант.

- Сначала реализовать basic wand, Thaumcraft Table/Arcane Workbench, обычный
  узел, зарядку, Очки и Arcane Stone.
- Оставить `NODEJAR` неактивным до отдельной вертикали, включающей честную
  классическую wand/Infusion progression достаточной ёмкости.

Плюс: не искажает TC4. Минус: исходный Definition of Done закрывается в два
этапа.

### B. Расширить scope до классической ёмкости

Разрешить advanced rods и Infusion, включая минимум Silverwood wand
capacity `100`, а также все реальные родители и рецепты.

Плюс: позволяет сохранить стоимость `70` и cap modifier. Минус: это крупное
расширение, прямо запрещённое текущим master prompt.

### C. Явно адаптировать механику

Официально разрешить одну из несовместимых с TC4 правок:

- снизить `NODEJAR` cost до значения, помещающегося в basic wand; или
- увеличить capacity wooden rod.

Плюс: вертикаль остаётся маленькой. Минус: это намеренное gameplay-расхождение,
которое должно быть отмечено в Thaumonomicon, status и release notes.
