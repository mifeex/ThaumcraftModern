# Classic Thaumcraft assets

This private development workspace contains selected textures, models, and
sounds extracted from the locally supplied `Thaumcraft 4.2.3.5` reference JAR.
They remain the property of their respective rightsholders.

Their presence is for local compatibility and visual-behavioural verification.
Do not publish or redistribute a build containing those assets unless you have
the required permission. The modern Java implementation is newly written and
does not mechanically copy the legacy source.
